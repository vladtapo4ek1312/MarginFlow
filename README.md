# MarginFlow

Веб-приложение для селлеров Wildberries и Ozon: расчёт ожидаемой прибыли с продажи отдельного товара.

Работает полностью в браузере — без бэкенда, авторизации и внешних API. Данные хранятся локально (localStorage).

**Открыть приложение:** https://vladtapo4ek1312.github.io/MarginFlow/

## Стек

- React + TypeScript
- Vite
- Vitest (юнит-тесты)
- oxlint (линтер)

## Команды

```bash
npm install         # установить зависимости
npm run dev         # dev-сервер (http://localhost:5173)
npm run build       # проверка типов + production-сборка в dist/
npm run typecheck   # только проверка типов
npm run lint        # линтер (oxlint)
npm test            # запустить тесты один раз
npm run test:watch  # тесты в режиме наблюдения
npm run preview     # локальный просмотр production-сборки
```

## Возможности

- **Обзор** — сводка по сохранённым товарам: количество, суммарная прибыль, средняя рентабельность,
  убыточные товары, сравнение маркетплейсов.
- **Калькулятор** — прибыль, рентабельность, наценка и точка безубыточности в реальном времени;
  комиссия фиксированной суммой или процентом от цены продажи, закупочной цены или своей суммы.
- **Мои товары** — сохранение, редактирование, удаление, поиск, фильтр по маркетплейсу,
  сортировка по прибыли, экспорт в CSV (UTF-8 BOM, разделитель «;» — открывается в Excel).

Навигация через hash (`#/calculator`, `#/products/<id>`) — работает на GitHub Pages и
сохраняет раздел при обновлении страницы.

## Структура

```
src/
  calculations/  чистые финансовые функции: profit.ts, portfolio.ts, money.ts
  storage/       localStorage с валидацией и защитой от повреждённых данных
  types/         общие типы
  utils/         форма, CSV, маршруты, форматирование, поиск и сортировка
  hooks/         useProducts, useHashRoute
  components/    layout/, calculator/, products/, ui/
  pages/         Обзор, Калькулятор, Мои товары
  App.tsx
  main.tsx
tests/           юнит-тесты Vitest
```

## Деплой на GitHub Pages

В `vite.config.ts` задан относительный `base: './'`, поэтому сборка из `dist/` работает
по адресу `https://<user>.github.io/<repo>/` без дополнительной настройки.

Деплой автоматический: каждый пуш в `main` запускает `.github/workflows/deploy.yml` —
линтер, тесты, проверку типов и сборку. Сайт обновляется, только если все проверки прошли.
Запустить вручную: вкладка **Actions** → **Deploy to GitHub Pages** → **Run workflow**.

В настройках репозитория (**Settings → Pages**) источником должен быть выбран **GitHub Actions**.
